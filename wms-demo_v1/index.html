시연 시나리오

① 점주 발주 → WMS 배송확정 → 앱 상태 반영

  1. 점주 앱에서 상품 담기
  2. 장바구니 확인 후 주문하기
  3. 발주 확정
  4. WMS 배송처리 목록에서 앱 접수 확인 → 배송확정
  5. 점주 앱 주문내역에서 출고 완료 확인

② 결품 처리 → 앱 대체 안내

  1. WMS 결품현황에서 결품 처리
  2. 점주 앱 주문상세에서 대체·결품 라인 확인

③ 후입금 한도 초과 차단

  1. 마이페이지에서 결제 유형을 후입금으로 전환
  2. 장바구니에서 한도 초과 금액으로 주문하기
  3. 발주 확정 화면에서 여신 한도 초과 차단 문구 확인
화면·데이터는 시연용 재구성이며 실제 운영 데이터가 아닙니다
